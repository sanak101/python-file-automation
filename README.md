# Python File Automation Scripts

This repository contains beginner to intermediate level Python automation scripts focused on file and folder management.

The purpose of this project is to demonstrate practical Python scripting skills that can be used for real-world automation tasks such as organizing files, filtering by extension, and managing directories efficiently.

---

## 📌 Features

- List all files in a directory
- Count total files
- Filter files by extension (.txt, .jpg, etc.)
- Case-insensitive file filtering
- Clean and readable Python scripting

---

## 🛠 Technologies Used

- Python
- os module (built-in)

---

## 📂 Example Tasks Implemented

✔ Print only `.txt` files  
✔ Print only `.jpg` files  
✔ Count total files in folder  
✔ Loop through directory contents  

---

## 🚀 Why This Project?

Manual file organization is time-consuming. These scripts demonstrate how Python can automate repetitive file management tasks, saving time and reducing errors.

This project reflects my ability to:
- Work with file systems
- Write clean loops and conditions
- Apply automation logic to real problems
